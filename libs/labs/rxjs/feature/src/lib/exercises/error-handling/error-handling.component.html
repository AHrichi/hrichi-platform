Architecture Rule: Inner vs. Outer Error Handling

Critical Best Practice

The most widespread bug in reactive Angular applications is attaching catchError to the wrong stream level.

The Pitfall: When an Observable encounters an unhandled error notification, the contract of RxJS terminates the stream permanently. If you place catchError after a switchMap (on the outer stream), any HTTP error permanently destroys user keystrokes!

Exercise: Bulk Operations

Using operators like forkJoin and bufferCount to handle multiple streams in parallel or in batches.

Configuration

forkJoin: All or Nothing

Waits for multiple Observables to complete and then emits an array of their last values.

Analogy: Ordering a multi-course meal. You have to wait for the appetizer, main course, and dessert to all be ready before the full meal is served.

bufferCount: Batch Processing

Collects values from the source Observable into a buffer until it reaches a specified size, then emits the buffer.

Analogy: A factory assembly line that waits to fill a box with {{ batchSize() }} items before sealing it and sending it to the next station.

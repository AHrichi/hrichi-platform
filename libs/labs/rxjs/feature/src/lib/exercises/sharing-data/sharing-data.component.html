Exercise: Sharing Data Between Components

Visualizing the different ways Angular components communicate with each other.

Parent to Child: Input()

The parent component passes data down to the child using an input binding.

Analogy: A parent giving a child a specific toy to play with. The data flow is one-way, from parent to child.

Parent Component

@if (animateParentToChild()) {
}
@if (showInputCode()) { 
// parent.component.ts
dataToSend = 'Hello Child';

// child.component.ts
            Input() data: string;
}

Child to Parent: Output()

The child component emits an event that the parent listens for.

Analogy: A child telling a parent they are hungry. The child initiates the communication, and the parent reacts to the event.

Parent Component

Received: {{ dataFromChild() || 'N/A' }}

@if (animateChildToParent()) {
}
@if (showOutputCode()) { 
// child.component.ts
            Output() dataEvent = new EventEmitter<string>();
sendData() { this.dataEvent.emit('Data from child'); }

// parent.component.html
<app-child (dataEvent)="onDataReceived($event)"></app-child>
}

Unrelated Components: Service

A shared service acts as a central hub for components to share data.

Analogy: A public announcement system at an airport. A gate agent (sender) makes an announcement, and all passengers (receivers) can hear it, regardless of where they are.

DataSharingService
@if (showServiceCode()) { 
// data-sharing.service.ts
private dataSubject = new BehaviorSubject<string>(null);
data$ = this.dataSubject.asObservable();
sendData(data: string) { this.dataSubject.next(data); }

// sender.component.ts
this.dataService.sendData('New Data');

// receiver.component.ts
this.dataService.data$.subscribe(data => ...);
}

Parent to Child: ViewChild()

The parent directly accesses the child component's properties and methods.

Analogy: A TV remote control. The parent (you) has direct access to the child's (the TV's) methods, like `turnOn()` or `changeChannel()`.

Parent Component

@if (showViewChildCode()) { 
// parent.component.ts
            ViewChild(ChildComponent) child: ChildComponent;
callChild() { this.child.childMethod(); }

// child.component.ts
childMethod() { console.log('Method called!'); }
}

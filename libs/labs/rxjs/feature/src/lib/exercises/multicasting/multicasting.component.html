Exercise: Multicasting

Exploring how to share a single Observable execution with multiple Observers.

Cold Observable

Each subscriber gets its own independent execution of the Observable.

Analogy: Watching a movie on Netflix. Each person who clicks play starts the movie from the beginning, getting their own private stream.

@for (subscriber of subscribers().cold; track subscriber.id) {
{{ subscriber.id }}'s Execution
@for (marble of subscriber.marbles; track marble.id) {
{{ marble.value }}
}
}

Hot Observable (with share())

All subscribers share a single execution. Late subscribers miss earlier values.

Analogy: Tuning into a live radio broadcast. Everyone hears the same song at the same time. If you tune in late, you miss the beginning.

Shared Source Stream
@for (marble of sourceMarbles().hot; track marble.id) {
{{ marble.value }}
}
@for (subscriber of subscribers().hot; track subscriber.id) {
{{ subscriber.id }}
@for (marble of subscriber.marbles; track marble.id) {
{{ marble.value }}
}
}

Hot Observable (with connectable)

Gives you manual control over when the shared execution starts via connect().

Analogy: A movie premiere. The audience (subscribers) can gather, but the movie (source) won't start until the projectionist (you) hits the play button (connect()).

Shared Source Stream
@for (marble of sourceMarbles().connectable; track marble.id) {
{{ marble.value }}
}
@for (subscriber of subscribers().connectable; track subscriber.id) {
{{ subscriber.id }}
@for (marble of subscriber.marbles; track marble.id) {
{{ marble.value }}
}
}

Subject

A basic multicast Observable. Observers only receive values emitted *after* they subscribe.

Source Stream
@for (marble of sourceMarbles().subject; track marble.id) {
{{ marble.value }}
}
@for (subscriber of subscribers().subject; track subscriber.id) {
{{ subscriber.id }}
@for (marble of subscriber.marbles; track marble.id) {
{{ marble.value }}
}
}

4. RxJS Interop: toSignal()

Convert an RxJS Observable into a read-only Signal to seamlessly integrate with a modern, signal-based component.

5. Angular 22: linkedSignal()

A writable signal that resets to a computed default whenever its source dependency changes, while still allowing direct user writes and overrides.

@let currentTier = planTier(); @let credits = computeCredits(); @let isCustom = isCreditsCustomized();

Why linkedSignal? With computed(), state is strictly read-only. With separate writable signals + effects, syncing is error-prone. linkedSignal() gives you the best of both worlds: reactive default syncing with writable capability!

{{ credits }}
@if (isCustom) { User customized (overridden) } @else { Plan default } 
// Angular 22 linkedSignal
planTier = signal<'Starter' | 'Pro' | 'Enterprise'>('Pro');

computeCredits = linkedSignal<PlanTier, number>({
  source: () => this.planTier(),
  computation: (tier) => (tier === 'Enterprise' ? 100 : tier === 'Pro' ? 25 : 5),
});

// Direct mutation allowed without breaking reactivity:
computeCredits.update(c => c + 5);

6. Angular 22: rxResource() Async Data Streams

Bridges asynchronous RxJS streams directly into declarative Signals with built-in loading flags, automatic cancellation on parameter change, and error boundaries.

@let resource = userProfileResource; @let profile = resource.value(); @let loading = resource.isLoading(); @let status = resource.status();

Async Data in Zoneless Angular: rxResource() executes an RxJS loader stream, exposing synchronous signals for value(), isLoading(), and status(), with complete SSR hydration safety and zero zone.js.

7. Bidirectional Interop: toObservable() & toSignal()

Taking values from a Signal, piping through RxJS operators (like debounceTime), and outputting back to a Signal.

// Signal -> Observable -> Operators -> Signal
searchQuery = signal('Angular 22');
searchQuery$ = toObservable(this.searchQuery);

debouncedSearch = toSignal(
  this.searchQuery$.pipe(
    debounceTime(350),
    map(q => q.toUpperCase().trim()),

Source Stream Configuration

The concatMap Operator

Maps each source value to an inner Observable and processes them in sequence. Guarantees order.

Analogy: A meticulous chef following a recipe. They complete one step (e.g., chopping vegetables) before starting the next (e.g., sautéing). The order is crucial.

{{ marble.value }}

}
}

{{ marble.value }}
}

{{ marble.value }}

The switchMap Operator

Switches to a new inner Observable when the source emits, cancelling the previous one. Ideal for cancellation.

Analogy: Typing in a search bar. You only care about the results for the latest thing you typed. Old searches are cancelled and discarded.

The mergeMap Operator

Subscribes to all inner Observables concurrently. Emits values as they arrive. Order is not guaranteed.

Analogy: Downloading multiple files at once. All downloads start immediately and run in parallel. The one that finishes first appears first.

The exhaustMap Operator

Ignores new source values while an inner Observable is active. Ready for the next source value only after completion.

Analogy: Repeatedly clicking a "Save" button. The first click starts the save process, and all other clicks are ignored until the first one is finished.

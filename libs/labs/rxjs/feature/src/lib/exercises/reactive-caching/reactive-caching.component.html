The first time a user is fetched, a simulated network delay occurs. Subsequent requests for the same user are served instantly from memory.

Analogy: Asking a librarian for a specific book. The first time, they retrieve it from the archive shelves (network request). If asked for the same book again, it remains immediately ready at the front desk (cache).

private cache = new Map<number, Observable<User>>();

fetchUser(id: number): Observable<User> {{ '{' }}
  if (this.cache.has(id)) {{ '{' }}

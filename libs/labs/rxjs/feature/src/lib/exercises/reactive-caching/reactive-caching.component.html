Exercise: Reactive Caching

Using the shareReplay operator to cache and share the results of an Observable stream, like an HTTP request.

User Data Caching

Click the buttons to fetch user data. The first time a user is fetched, it will simulate a network delay. Subsequent requests for the same user will be served instantly from the cache.

Analogy: Asking a librarian for a specific book. The first time, they have to go to the shelves to find it (a network request). If you ask for the same book again, they have it ready at the front desk (the cache).
